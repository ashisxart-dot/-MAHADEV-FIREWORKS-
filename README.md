# -MAHADEV-FIREWORKS-
Mobile-friendly fireworks store for Mahadev Fireworks. Customers browse 100 crackers in 7 categories, search by name, add items to a bag with quantities, and send the full order with their name and address to the shop on WhatsApp. One HTML file, no payment or login, no server needed. Free to host on GitHub Pages or Netlify. Easy to edit.
